# DuoBox – Eat • Play • Win • Reuse 🥪🥤

The game website for **DuoBox**, a Year 6 Young Entrepreneurs project at International Kingdom College.

Scan the QR code on the box, solve 5 maths questions or riddles in a row, earn 100 points and win a free slush!

The whole game is one file: `index.html`. To update it, replace that file and GitHub Pages republishes it automatically.
